# Data

## In this repository

| File | Content |
|---|---|
| [data/candidates_final.csv](../data/candidates_final.csv) | all 61 Li-bearing candidates: formula, atoms, `e_above_hull`, hull decomposition, convergence, unique / novel / stable / S.U.N. flags, the cutoff, the conductivity prior (mean, σ, spread), AD distance, OBELiX match, extrapolation flag, score rank and S.U.N. rank |
| [data/p3_runs.json](../data/p3_runs.json) | run record: parameters, funnel counts and where each count comes from, scorer identity (Project 1 commits, manifest sha256, route thresholds), outputs, and the previous runs |
| [data/ref_structures.json](../data/ref_structures.json) | the 96 Materials Project reference phases of the Li-P-S hull as pymatgen `Structure` dictionaries, so the hull runs without an MP API key |
| [source_data/](../source_data/) | the values plotted in each figure ([figures.md](figures.md)) |
| [vendor/](../vendor/README.md) | the vendored Project 1 ensemble, its manifest and the 599 OBELiX training formulas (CC BY 4.0) |

## Not in this repository

Regenerated by the pipeline and ignored by git (`.gitignore`): raw MatterGen output
(`data/mattergen_run/`), generated and relaxed structures (`data/generated/`, `data/relaxed/`), the
intermediate tables `data/screened.csv` and `data/scored.csv`, reference-energy caches, and the
quick-look figures `figures/01_landscape.png` and `figures/02_shortlist.png`. Model weights
(MatterGen, MACE-MP-0) are downloaded at run time.
